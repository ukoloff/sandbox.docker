# SideCar

Контейнер для
1. Загрузки содержимого репозитория (-ев)
2. Выполнения кода
3. Донастройки других контейнеров

## Клонирование git

Поддерживаемый формат URL:
`[https://github.com/]ukoloff/sandbox.docker[/sidecar][?slug=1&depth=3&ref=test&dev=1][#sidecar]`
+ Если не указан сайт - берётся GitHub
+ Если указана подпапка, клонируется только она, не весь репозиторий    
    + Положение папки в URL можно указать параметром `slug`, по умолчанию 2
+ Если не указана ветка, клонируется HEAD (master/main)
    + Ветку можно указать параметром `ref` или `#ref`
+ В любом случае только один (последний) коммит
    + Или на глубину параметра `depth`
+ Если указан параметр `dev`:
    + По умолчанию `depth=2`
    + Подгружаются все служебные файлы / папки из корня `\.*`

## Выполнение скриптов

После загрузки репозитория git,
в нём ищется подпапка `.sidecar`,
в ней - файлы `*.sh`,
они сортируются по имени файла
и исполняются при помощи `/bin/sh`.

Если необходимо загрузить дополнительные репозитории -
используйте команду `sidecar-git`.
Она также попытается выполнить скрипты
из этого репозитория.
